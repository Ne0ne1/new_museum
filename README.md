# Интерактивное семейное древо

Локальный музейный прототип на React, TypeScript и Vite. Все демонстрационные связи и биографические сведения явно помечены и должны быть заменены после проверки сотрудниками музея.

## Запуск

```bash
npm install
npm run dev
```

Для проверки производственной сборки: `npm run build`, затем `npm run preview`.

## Где менять содержание

- `src/data/people.ts` — имена на русском и чеченском, связи, даты, внутренние источники и происхождение временных фотографий. Источники посетителю не показываются.
- `public/portraits/` — локальные портреты. Имя файла должно совпадать с путём `photo` в данных.
- `src/styles.css` — цвета, размеры карточек и музейная компоновка.

Статус `demo` показывает пометку «Требуется подтверждение музеем». Не снимайте её до научной проверки записи.
